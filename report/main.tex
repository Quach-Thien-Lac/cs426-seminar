\begin{abstract}
	Mobile applications depend not only on the security of the code running on the device, but also on the availability and integrity of their supporting APIs and databases. This report studies three representative risks through Sanguosuo, an Android wiki for the Sanguosha board game: application-layer denial-of-service attacks, SQL injection, and password disclosure. We relate each risk to a defensive design based on bounded HTTP resources, parameterized database access, and adaptive password hashing. Inspection of the prototype confirms that its Express and MySQL backend consistently uses SQL placeholders and stores bcrypt password hashes. It also reveals important limitations: explicit Slowloris defenses are not yet configured, client--server traffic is cleartext during local development, authentication tokens are handled inconsistently, and the automated tests remain placeholders. The resulting evaluation therefore separates implemented protections from proposed hardening and identifies the work required before production deployment.
\end{abstract}
