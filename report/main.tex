\begin{abstract}
Sanguosuo is an Android wiki application for Sanguosha, a strategy card and board game set in the Three Kingdoms era of Chinese history. The application serves fans and players by providing a searchable, structured reference for heroes, skills, factions, and card combinations. This report documents the project topic and motivation, the intended target users, the application architecture, the technologies employed across the full stack, setup and installation procedures for local development, a work-division table, and a self-assessment of the features and quality delivered. The system is built with Kotlin and Jetpack Compose for the Android client, Express with TypeScript for the backend API, MySQL for persistent storage, and Docker Compose for local orchestration. Security considerations---including SQL injection prevention, password hashing, and denial-of-service awareness---were incorporated as a deliberate learning objective for the CS426 seminar component.
\end{abstract}
